# Bodies

One body per build. They all share the neck, the cavity, the base plate
snaps and the USB notch, so any body takes the same core parts. Print them
upright with tree supports from the build plate only: under the arms,
legs, collar, hood, tail, backpack and whatever the body holds on its lap.

| File | What it looks like | Builds that use it |
|---|---|---|
| `body_bare.stl` | The template: plain body with a collar | Template, Bunny, Unicorn |
| `body_skeleton.stl` | Rib relief, sternum and spine; thin bones for arms and legs | Skeleton |
| `body_hoodie.stl` | A hoodie, with the hood hanging down the back | DJ, Bear, Bug, King (and Gamer) |
| `body_cat.stl` | The hoodie with a tail | Cat, Devil, Dino |
| `body_astro.stl` | Suit collar and a backpack | Astronaut |
| `body_claude.stl` | An open laptop on the lap, a spark in relief on the back | Claude |
| `body_gamer.stl` | The hoodie, with a game controller held in both hands | Gamer |
| `body_robot.stl` | No collar; a chest panel with a grille and two buttons | Robot |
| `body_halloween.stl` | A jack‑o'‑lantern with a carved face | Halloween |
| `body_xmas.stl` | A present with a ribbon and a bow | Christmas |
| `body_ocean.stl` | A life ring with rope wraps | Ocean |
| `body_birthday.stl` | A cake with frosting and a candle | Birthday |
| `body_valentine.stl` | A big heart, held up | Valentine's |
| `body_summer.stl` | No collar; a beach ball | Summer |
| `body_stpatricks.stl` | A pot of gold with coins | St. Patrick's |

The thin arm bones of `body_skeleton` need support along their length;
remove it gently. The accessories each build wears are in
[`../accessories/`](../accessories/).
