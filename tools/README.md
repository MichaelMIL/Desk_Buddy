# tools

Helpers for working on the desk buddy that are not part of the simulator,
the firmware or the apps.

| Tool | What it does |
|---|---|
| [`firmware/`](firmware/README.md) | Firmware build and flash, in the browser: pick the settings (Wi-Fi, Bluetooth, USB serial only, battery level) and build. Then flash from the browser (web flasher), over USB with PlatformIO, or over Wi-Fi. A Wiring tab shows what to connect for the chosen settings. |
